# 확정 아키텍처·컨벤션 (Decisions Log)

> 이미 정해진 아키텍처·컨벤션 레퍼런스. **한 번 정한 것을 다시 묻지 않기 위한** 문서.
> 변경하려면 먼저 이 문서를 업데이트하고 [PROJECT.md](../PROJECT.md)에 반영할 것.

## 구조·동시성

- **루트 플랫 구조** — 서브디렉터리 금지 ([PROJECT.md](../PROJECT.md) §5 근거). 신규 모듈은 루트에 단일 파일로 추가.
- **단일 프로세스 asyncio** — `asyncio.gather()` 기반. 멀티프로세스·멀티스레드 제안 금지.
- **테스트 러너** — `python test.py` 단일 엔트리포인트. pytest 도입 제안 금지.

## 매매 전략

- **지정가 전용** — 시장가 주문 신규 도입 금지 (C1에서 시장가→지정가 전환 완료).
- **수수료 모델 일원화** — 매수 시점 차감, 매도 경로는 매도 수수료만 (A8에서 확정).
- **불변 수치** — 손절매·1% Rule·킬스위치는 Adaptive 피드백 대상 아님 ([PROJECT.md](../PROJECT.md) §4.7).
- **SEED 비율 계산** — 금액 하드코딩 금지, 모두 `config.py`의 SEED 비율로 계산.

## API·안전장치

- **ccxt 설정** — `enableRateLimit=True` 필수.
- **예외 처리** — 모든 API 호출에 `try-except` 필수, 오류 즉시 텔레그램 보고.
- **API 키** — 서버 IP 화이트리스트 필수, 출금 권한 절대 부여 금지.
