# 문서화 규칙 (Documentation Rules)

1. **PROJECT.md 업데이트:** 로직에 중요한 변화가 생길 때마다(특히 매매 전략이나 API 호출 관련) [PROJECT.md](../PROJECT.md)를 즉시 업데이트할 것.
2. **TODO.md 즉시 반영:** [TODO.md](../TODO.md)에 명시된 작업이 완료되면, 지체 없이 완료 표시(Check-off)를 할 것.
3. **기록 후 실행:** 새로운 버그가 발견되거나 새로운 기능이 계획되면, 구현을 시작하기 전에 반드시 TODO.md에 먼저 추가할 것.
4. **WORKFLOW.md 즉시 반영:** 작업 완료 즉시 [WORKFLOW.md](../WORKFLOW.md) 완료 테이블에 추가하고 해당 항목을 삭제할 것. 세션 종료 전 미완성 작업은 "현재 작업" 섹션에 진행 상황을 기록할 것.
