# 배포 가이드 규칙 (Deploy Advisor)

> 코드 변경을 만든 세션이 끝날 때, **Lightsail 반영에 필요한 특수 단계**를 사용자에게 자동 안내하는 규칙.
> 진단 로직은 [deploy/advise.sh](../deploy/advise.sh) 가 담당한다. 이 스킬은 호출 시점과 출력 형식만 정의.

## 트리거 조건

**파일 종류 불문, 세션에서 1개 이상 파일을 수정했으면 항상 실행.**
배포 필요 여부 판정은 `advise.sh` 가 담당 (🚨 배포 필요 / 🟢 배포 선택 / 🔘 배포 불필요 3등급).
문서만 수정한 세션도 "🔘 배포 불필요" 결과를 첨부해서 사용자가 명확히 알 수 있도록 한다.

## 실행 명령

세션에서 수정한 파일 목록을 `--files` 인자로 전달:

```bash
bash deploy/advise.sh --files <수정된 파일들 공백 구분>
```

출력 전문을 **응답 마지막**에 마크다운 코드블록으로 첨부.
사용자 설명 뒤에 한 번만, `---` 구분선 뒤에 붙인다.

## 출력 예시 (응답 말미)

```
---
(advise.sh 출력 전문을 여기에 그대로 첨부 — ANSI 색상 코드는 터미널용이므로 마크다운으로 첨부 시
\`\`\`text 블록 또는 일반 텍스트로 포함)
```

## 원칙

1. **로직 중복 금지** — 진단 규칙은 `deploy/advise.sh` 한 곳에서만 관리. Claude 는 스크립트 출력을 수정하지 않고 그대로 전달.
2. **한 세션 한 번만** — 동일 세션 내 여러 수정이 있어도 마지막 응답 끝에 한 번만 첨부.
3. **판정은 스크립트에 위임** — "배포 필요/선택/불필요" 는 advise.sh 가 파일 분류 규칙으로 결정. Claude 가 임의 판단하지 않는다.
